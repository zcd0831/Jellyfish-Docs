# 实现过程的模型改动记录

> 规矩：**任何**对 `Jellyfish-Docs/model/` 的改动（7 份领域文档 + 技术决策 + 本文件）都要在这里留一条记录。
> 顺序：先经同意 → 改 markdown → 在本文件追加记录 → 再改代码。**没记录的模型改动，视为没发生**（`AGENTS.md` 工作原则 5）。
>
> 一条记录的固定字段：**编号 / 日期 / 触发切片 / 为什么改 / 改了什么（前 → 后）/ 涉及文件 / 代码落点 / 验收方式**。
> 编号只增不改，**编号永不复用**；被推翻的记录标注 `状态：被 Mxx 取代`。
> 一条记录一旦核实"已完整落进模型"，其**正文连同索引行一起清理掉**（不留台账：要查历史就看 git）；清理动作本身不单独编号。
