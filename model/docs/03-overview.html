3.4模块与分层归属表

归属定位聚合服务 / 组件端口
感知 模型此刻能看到什么：上下文流水 + 快照 + 窗口折叠 + 运行环境策略 Session、RuntimePolicy SystemPromptAssembler（领域）；StartSessionUseCase、ContextWindowService、SessionTitleGenerator（应用） 声明 ModelInvocationPort
行动 能做什么 / 用什么做 / 花多少钱：工具、模型、代理、预算、插件 ToolDefinition、Provider、Model、AgentDefinition、Budget、PluginManifest ToolExecutor、BudgetService（应用）；ModelInvoker（基础设施，实现 ModelInvocationPort） ExternalToolPort、PluginRepository、PluginRuntimePort
规划 想怎么做 / 做到哪 / 算不算做成 Plan、VerificationReport PlanFactory、VerificationChain（领域）；ExecutionLoop、ReActLoop、VerificationRunner（应用） —
记忆 学到的东西如何留存与复用（经验 + 技能自动沉淀） Experience、Reflection、SkillDefinition ExperienceRetriever、PlanCompletionCurator、ExperienceDistillationService、SkillDistillationService、ExperienceFeedbackService（应用） 声明 SkillSopProvider（由基础设施 FileSkillSopProvider 实现）
应用层 用例编排、事务与提交顺序、端口契约、并发 —（只编排，不持有聚合） 8 个用例 + 17 个组件（见 第 8 章） 定义并被基础设施实现
基础设施层 端口背后：文件、模型、终端、时钟 — 22 个适配器（见 第 9 章） 实现 21 个端口（HumanInteractionPort / ProgressPort 由外壳实现，CancellationRegistry 由应用层实现）

  1. 需要别人的内容 → 让调用方取好，用值对象传进来。 例：AgentSnapshotInput、DistillationInput、RetrievalInput、FeedbackInput、ModelInvocationRequest。
  2. 需要别人的动作 → 走端口。 例：ModelInvocationPort（应用层声明 / 基础设施实现）、ExternalToolPort、SkillSopProvider、HumanInteractionPort。
  3. 只读别人的聚合不算依赖。 例：记忆按 RecordRange 只读 Session.Record；但绝不追写。

3.8事件全景

领域事件由聚合根在状态真的改变后发出，代表"这件事已经发生了"。 应用层在事务提交后才发布，订阅方只看 ID 和事件内容。

总口径：领域事件只通知
事件不得驱动任何 IO，也不得作为跨模块协作的触发手段；需要别的模块做事时，由应用层显式调用（ExecutionLoop 调检索 / 沉淀 / 反馈，ManageSessionUseCase 做级联终止）。因此下表的「谁关心」一列只列界面 / 审计这类无副作用消费。
事件谁发出什么时候谁关心
PlanCreatedPlan计划校验通过并创建无功能性订阅方：经验分配由 ExecutionLoop 显式调用；事件只供界面/审计
PlanCompletedPlan所有步骤成功无功能性订阅方：沉淀由 ExecutionLoop 显式调用；事件只供界面/审计
PlanFailedPlan外循环判定重划用尽并终止无功能性订阅方：沉淀由 ExecutionLoop 显式调用；界面 / 审计
StepFailedPlan标记步骤失败无功能性订阅方：外循环读标记后的聚合状态
VerificationRejectedVerificationReport结论为不通过 / 无法判定无功能性订阅方：外循环直接用验证返回值
ReflectionRecordedReflection反思结论落库无功能性订阅方：回注与沉淀素材均由外循环显式读取
